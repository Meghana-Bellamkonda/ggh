# 2024 Girl Hackathon Ideathon Round: Solution Submission


## Brief summary
The evolution of AI has propelled us into an era where machines possess remarkable capabilities to address
pressing challenges. As we harness this power, let's focus on solutions that have a tangible impact on people's lives.
With this aim in mind, we advocate for the creation of a healthcare recommendation system. Utilizing user
symptoms, mock data, healthcare provider databases, and user ratings, this system will suggest doctors who
specialize in relevant fields and have compatible schedules.


## Getting Started

1. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/Meghana-Bellamkonda/ggh
2. Navigate to project directory 

   ```bash
   cd ggh 
3. Install dependencies 
   ```bash
   npm install 
       or
   yarn install 
4. Setup open ai and clerk api key 
create a .env.local file and add your keys 
   ```bash  
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
   CLERK_SECRET_KEY=
   OPENAI_API=
   ```
5. Run locally 
    ```bash
    npm run dev
        or
    yarn run dev
    ```
